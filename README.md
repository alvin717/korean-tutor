# K-Lingo (korean-tutor)

듀오링고 스타일의 한국어 학습 모바일 앱 아키텍처 제안서 및 적응형 학습 인터랙티브 프로토타입입니다. Google AI Studio에서 생성되었습니다.

## 주요 기능

모바일 프레임 시뮬레이터: 실제 앱처럼 체험하는 레슨 UI
레슨/퀴즈 모달, 하트 시스템, XP/스트릭/리그 랭킹
간격 반복 학습(SRS) 복습 아이템 관리
AI 기반 알림 시뮬레이터 (Multi-Armed Bandit)
기술 명세서(Specs Deck) 보기: 시뮬레이터와 명세를 나란히 보는 Dual 모드

## 기술 스택

React 19, TypeScript, Vite 6, TailwindCSS 4, Google Gemini API (@google/genai), Framer Motion, Lucide Icons

## 실행 방법

```
npm install
npm run dev
```
